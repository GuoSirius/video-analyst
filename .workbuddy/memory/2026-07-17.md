## 每任务自定义 fetch 超时（S2/S3 增强）
- 用户需求：每个爬取任务可自设请求超时；0=不限；省略=默认15000；非法值回退默认（不报错）。
- 改动（提交 d75e591，未推送）：
  - `server/src/crawler/crawler.service.ts`：`CrawlPayload` 加 `fetchTimeoutMs?: number`；`fetchHtml` 在 `timeoutMs<=0` 时不挂定时器/不设 signal（防 naive `setTimeout(...,0)` 导致立即 abort）。
  - `server/src/crawler/crawler.controller.ts`：新增 `resolveFetchTimeout(payload)` 归一化（undefined→15000 / 0→0 / 正整数→原值 / 非法→15000+console.warn）；`processCrawlTask` 与 `recrawlSingleItem` 各自取 `timeoutMs` 后透传到 `fetchWithRetry` 与 3 处直连 `fetchHtml`；`startCrawl`/`updateTask` 写入干净值。
  - `web/src/pages/CrawlerTasks.vue`：执行选项区加「请求超时(ms)」数字输入框（null=默认，0=不限，附 tooltip）。
- 坑：单项重采 `recrawlSingleItem` 是独立方法，`timeoutMs` 不在 `processCrawlTask` 闭包内，需在该方法内单独 `const timeoutMs = this.resolveFetchTimeout(payload)`。
- 验证：server build 0 TS issues；web build 5.59s。电脑中途自动关机，重跑编译+提交补齐。

## 修复：CrawlerItems 切换任务清空多选
- 现象：采集列表页之前多选+翻页/搜索保持选中，但一切换任务下拉就清空。
- 根因：`web/src/pages/CrawlerItems.vue:441` 有 `watch(selectedTaskId, () => { ...selectedIds.value=[]; clearSelection() })` 在任务变化时主动清空全局选中项。
- 修复：删除该 watch。`selectedIds` 本按全局 item UUID 存、天然跨任务持久；`syncTableSelection()`（fetch 后调用）会把选中项重新勾上；`reserve-selection`+`row-key=id` 也辅助保留。
- 注意：删除后「重置筛选」(resetFilters) 也不再清选中——符合用户"一直保持"需求；清空仍由专用「清空选择」按钮负责。跨任务批量操作会作用于所有已选项（N 个任务合并），属该行为的自然结果。
- 验证：web build 5.07s 通过；dev server 在跑（3000/5173 监听），刷新即测。

## 采集列表导出：恢复「按任务分组」
- 诊断：用户记忆中"按任务划分"功能没丢，只是它挂在**任务页** `CrawlerTasks.vue` → `POST /crawler/export`（单文件多Sheet / 多文件zip）；而**采集列表页** `CrawlerItems.vue` 一直走 `POST /crawler/export-items`（把所有勾选项塞进一个 sheet，无分组）。git 证实列表页自 e5b6f9f 多选引入起就用 export-items，从未调过分组版。
- 关键缺口：列表页导出若直接复用任务页 `exportData` 会忽略勾选（按整任务导出）。故**增强 export-items 而非替换**：按 `task_id` 分组、且只导出勾选的 `itemIds`。
- 改动（提交 047e461，未推送）：
  - `server/src/crawler/crawler.controller.ts` 的 `exportItems`：查 `WHERE id IN (itemIds)` → 按 task_id 分组 `byTask` → 跨任务时：`multiFile` 为真出 zip 多 .xlsx；否则单 xlsx 多 sheet；json/yaml 出分组对象；csv 出 zip。单任务保持原单文件。
  - `web/src/api/modules/crawler.ts`：`exportItems` 入参加 `multiFile?: boolean`。
  - `web/src/pages/CrawlerItems.vue`：`selectedItemsMeta` 加 `task_id`；导出弹窗加「单文件多Sheet / 多文件」切换（仅跨任务且非 csv 时显示）；`loadExportFields` 的 taskIds 同时取自 `selectedItemsMeta`（覆盖跨任务离屏选中）；`doExport` 传 `multiFile`。
- 验证：重启 dev（加载新后端）实测跨任务导出——multiFile=true 返回 zip 含 2 个按任务命名的 .xlsx；multiFile=false 返回单 xlsx 含 2 个按任务命名的 sheet；每行数据 = 表头+2（正好每任务勾的 2 条，非整任务 13 条），确认"只导出勾选"。
